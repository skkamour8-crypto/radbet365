# radbet365

مشروع Laravel مستقل لمنصة ألعاب ترفيهية بأرصدة نقاط افتراضية فقط.

## النطاق
- لا توجد إيداعات أو سحوبات أو مراهنات مالية أو جوائز نقدية.
- الحسابات الجديدة تبدأ برصيد **0 نقطة**.
- لوحة إدارة محمية لإدارة أرصدة النقاط.
- لا يوجد قسم رياضي.

## المتطلبات
- PHP 8.2 أو أحدث
- Composer 2
- SQLite (مهيأة افتراضياً) أو MySQL مع إعدادات البيئة المناسبة

## التثبيت
```bash
composer install
cp .env.example .env
php artisan key:generate
mkdir -p database && touch database/database.sqlite
php artisan migrate --seed
php artisan serve
```

## إنشاء حساب المدير
1. شغّل الموقع وسجّل حساباً عادياً بالبريد الذي ستستخدمه كمدير.
2. من طرفية الخادم نفّذ الأمر التالي مع بريد حسابك:
```bash
php artisan radbet365:make-admin your-email@example.com
```
3. سجّل الخروج ثم الدخول مجدداً. سيظهر رابط «الإدارة» في القائمة.

لا يوجد رابط عام لإنشاء مدير؛ منح صلاحية المدير يتم من طرفية الخادم فقط.

## إدارة النقاط
من لوحة الإدارة يمكن إضافة أو خصم نقاط افتراضية. يمنع النظام جعل الرصيد سالباً، ويسجل كل تعديل مع المدير والسبب والرصيد بعد التعديل في سجل الحركات.

## الحالة
هذا إصدار تأسيسي قيد التطوير. يلزم تثبيت Composer وتشغيل migrations واختبارات على استضافة فعلية قبل الاستخدام العام. GitHub يحفظ الكود ولا يشغّل تطبيق Laravel بذاته.
