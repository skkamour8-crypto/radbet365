# radbet365

مشروع Laravel مستقل لمنصة ألعاب ترفيهية بأرصدة نقاط افتراضية فقط.

## النطاق الحالي
- لا توجد إيداعات أو سحوبات أو مراهنات مالية أو جوائز نقدية.
- الحسابات الجديدة تبدأ برصيد 0 نقطة.
- لوحة تحكم إدارية لإدارة الألعاب والأرصدة ستُستكمل في المراحل التالية.
- لا يوجد قسم رياضي.

## المتطلبات
- PHP 8.2 أو أحدث
- Composer 2
- امتدادات PHP المطلوبة من Laravel 12
- قاعدة بيانات SQLite أو MySQL

## التثبيت
```bash
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate --seed
php artisan serve
```

هذا المستودع يحتوي على هيكل بداية للمشروع، وليس نسخة منشورة أو تطبيقاً مكتملاً بعد.
